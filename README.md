# TSUKASA Walkabout

A walkable pixel-art preview of TSUKASA, a Japanese select shop, café and tea room.

Plain static site, no build step: `index.html` loads `a.js` (map, walls), `b.js` (props) and `c.js` (characters, dialogue, game loop). Open `index.html` in a browser to play locally. Pushes to `main` deploy to Vercel.
